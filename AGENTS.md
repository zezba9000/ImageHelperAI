# ImageHelperAI
- OpenAI key is set via environment var "OPENAI_API_KEY"
- Main Window is a set of tabs for different future features

# Sides Tab
- Sides tab lets user select a source image
- A set of checkboxes for back, front, left, right, bottom, top can be checked
- Side checkboxes tell OpenAI what image sides to generate from source
- A Generate button sends data to OpenAI to generate images and place them against a white background
- Resulting images returned from OpenAI display in a grid
- A Save button lets you save results to a selected folder
